# Формальна специфікація SIPL

Версія мови: **SIPL-base 1.0**. Машинозчитувана граматика — `src/sipl/grammar/sipl.lark`
(формат Lark, LALR(1)). Саме цей файл завантажує парсер, тож документ і реалізація не розходяться.
Показати граматику з коду: `python -c "import sipl; print(sipl.grammar_text())"`.

## БНФ курсу

За практикумом (практична робота 1, с. 8):

| Метазмінна | Правило | Назви правил |
| --- | --- | --- |
| `<програма>` = P | `begin S end` | NP1 |
| `<оператор>` = S | `x := a` \| `S1 ; S2` \| `if b then S1 else S2` \| `while b do S` \| `begin S end` \| `skip` | NS1–NS6 |
| `<вираз>` = a | `n` \| `x` \| `a1 + a2` \| `a1 - a2` \| `a1 * a2` \| `(a)` | NA1–NA6 |
| `<умова>` = b | `a1 = a2` \| `a1 > a2` \| `b1 ∨ b2` \| `¬ b` \| `(b)` | NB1–NB5 |
| `<змінна>` = x | `… M` \| `N …` | NV… |
| `<число>` = n | `… -1` \| `0` \| `1` \| `2` \| `…` | NN… |

## Відповідність правил

| БНФ | Правило граматики | Вузол AST |
| --- | --- | --- |
| `begin S end` (програма) | `program` | `Program` |
| `x := a` | `assign` | `Assign` |
| `S1 ; S2` | `seq` | `Seq` |
| `if b then S1 else S2` | `if_stmt` | `If` |
| `while b do S` | `while_stmt` | `While` |
| `begin S end` (оператор) | `block` | `Block` |
| `skip` | `skip` | `Skip` |
| `n` | `factor` → `NUMBER` | `Num` |
| `x` | `factor` → `VAR` | `Var` |
| `a1 + a2`, `a1 - a2` | `expr` | `BinOp` |
| `a1 * a2` | `term` | `BinOp` |
| `(a)` | `factor` | немає вузла |
| `a1 = a2`, `a1 > a2` | `batom` | `Compare` |
| `b1 ∨ b2` | `cond` | `Or` |
| `¬ b` | `bneg` | `Not` |
| `(b)` | `batom` | немає вузла |

## Пріоритети

БНФ курсу неоднозначна: `2 + 3 * 4` чи `S1 ; S2 ; S3` мають кілька дерев виводу. Практикум знімає
неоднозначність угодами про пріоритети, а граматика тут записує ці угоди явно, розшаровуючи правила.
Множина коректних програм при цьому не змінюється.

| Від найсильнішого до найслабшого | Асоціативність |
| --- | --- |
| `*` | ліва |
| `+`, `-` | ліва |
| `=`, `>` | не асоціативні: `A = B = C` — помилка |
| `¬` | префіксна |
| `∨` | ліва |
| `:=`, `if`, `while` | тіло циклу та гілки `if` — один оператор |
| `;` | права: `S1 ; S2 ; S3` = `S1 ; (S2 ; S3)` |

Праве вкладення `;` взято з дерев виводу практикуму; на результат виконання воно не впливає,
бо композиція асоціативна.

Наслідок останніх двох рядків: у `while B do S1 ; S2` оператор `S2` стоїть після циклу. Щоб обидва
оператори були тілом циклу, потрібен блок `begin S1 ; S2 end`. Так само сформульовано в практикумі.

## Дерево виводу

`sipl tree` показує дерево виводу в нотації практикуму: внутрішні вузли — метазмінні
`<програма>`, `<оператор>`, `<вираз>`, `<умова>`, `<змінна>`, `<число>`, листки — термінали.
Кожен внутрішній вузол — одне застосування правила з таблиці вище. Допоміжні правила граматики
Lark (`seq`, `stmt`, `term`, `factor`, `bneg`, `batom`), які існують лише для пріоритетів,
у дерево не потрапляють.

## Лексика

| Лексема | Опис |
| --- | --- |
| Ключові слова | `begin end if then else while do skip or not` — лише малими літерами |
| Змінна | латинська літера, далі літери, цифри або `_`: `[A-Za-z][A-Za-z0-9_]*`; регістр має значення |
| Число | десяткові цифри `[0-9]+`; від'ємне число записується як `-5` |
| Оператори | `:=  ;  +  -  *  =  >  (  )` |
| Логічні операції | `∨` або `or`; `¬` або `not` |
| Коментар | від `//` до кінця рядка |
| Пробіли | пробіл, табуляція, перенесення рядка — розділяють лексеми й ігноруються |

Ключове слово не може бути змінною, але може бути частиною імені: `beginx`, `do1` — звичайні змінні.

## Уточнення відносно БНФ

БНФ практикуму не визначає повністю категорії змінних і чисел та використовує символи, яких немає
на клавіатурі. Ця версія фіксує такі рішення:

1. **Змінні** — довільні ідентифікатори (у БНФ перелік позначено трьома крапками).
2. **Від'ємні числа** — `-` безпосередньо перед числом у позиції операнда: `X - -3`, `X * -2`.
   Унарного мінуса перед змінною чи дужкою немає: `-Y` — помилка, слід писати `0 - Y`.
3. **ASCII-запис** — `or` та `not` як синоніми `∨` та `¬`; AST для обох записів однакове.
4. **Коментарі** `//` — лексичне розширення, на синтаксис не впливає.
5. **`;` є роздільником**, а не завершувачем: `X := 1; end` — помилка, як і в БНФ.
6. **Порожнього оператора немає**: замість нього `skip`.

## Семантичні угоди інтерпретатора

- Значення змінних — цілі числа без обмеження розрядності.
- Читання змінної, якої немає в стані, дає невизначеність: виконання зупиняється з діагностикою `E101`.
- `∨` строга: обчислюються обидва операнди, тож невизначений операнд робить невизначеною всю умову.
